about=Adds a Feature Dataset concept (as in Esri File Geodatabases) to GeoPackage files. A dataset stores its CRS once; new layers created inside it inherit that CRS automatically, existing layers are checked against it. The grouping is stored in two small helper tables inside the .gpkg, which other software ignores.
