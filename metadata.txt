about=Adds a Feature Dataset workflow to GeoPackage, SpatiaLite and File Geodatabase. Choose the storage format first, then create datasets with a CRS that is set once; new layers created inside a dataset inherit it automatically, existing layers are checked against it (with an optional reprojected copy), and a validation report lists any mismatch. GeoPackage and SpatiaLite keep the dataset definitions in two small helper tables inside the file; File Geodatabase uses its real feature datasets (needs GDAL 3.6+).
